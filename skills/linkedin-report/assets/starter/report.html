실제 설문이나 현장 조사를 수행하지 않았습니다. 12개 team이 4주 동안 주문을 처리했다는 상황을 가정하고, 편집에 필요한 작은 data를 만들었습니다.

관찰 단위
주문 1,200건 중 예외 주문 240건. 각 주문의 지연 이유는 한 개로 배정했습니다.
예외 주문
표준 흐름에서 벗어나 추가 확인이 필요한 주문입니다. 전체 주문 대비 예외 비율은 240 ÷ 1,200 = 20%입니다.
지연 이유
담당자 확인 96건, 정책 확인 72건, data 보정 48건, 시스템 재시도 24건. 합계는 240건입니다.
비교 집단
담당 기준 명시 / 개별 확인. 집단마다 6개 team, 예외 주문 120건을 배정했습니다.
당일 확정
관찰 당일 담당자가 다음 조치를 정한 주문입니다. 기준 명시 집단 90건, 개별 확인 집단 54건입니다.

이 예제가 말할 수 없는 것

수치는 실제 조직의 성과, 시장의 비율 또는 정책의 효과를 추정하지 않습니다. 두 집단의 차이는 비교 편집을 보여주기 위한 설정이며, 통계 검정이나 인과 분석을 수행하지 않았습니다.

01 · 확인이 반복되는 예외부터 고릅니다

가상 data의 담당자·정책 확인 168건처럼 큰 묶음의 세부 유형을 봅니다. 비중이 크다고 모두 같은 문제는 아닙니다.

02 · 인계 조건을 한 문장으로 씁니다

필요한 정보가 채워졌을 때 누구에게 넘길지 정합니다. 담당자 이름만 적으면 정보 부족으로 다시 기다릴 수 있습니다.

03 · 다음 관찰에도 같은 정의를 씁니다

당일 조치 확정과 해결 완료를 구분해서 기록합니다. 운영 규칙의 변화와 주문 조건을 함께 남깁니다.

개념도와 운영 제안은 가상 data [2–3]를 읽는 제작용 예시입니다. 검증된 개선 효과를 주장하지 않습니다. 근거와 한계의 목록.
